# typescript

Proyecto TypeScript inicial (configuración `strict`).

## Requisitos

- Node.js (incluye `npm`)

## Instalación

```powershell
npm install
npm install typescript --save-dev
```

## Compilar

```powershell
npm run build
```

## Ejecutar

```powershell
npm start
```

## GitHub

Para publicar en GitHub hace falta crear el repo `typescript` y conectar el remoto (`git remote add origin ...`), o tener autenticación con `gh`.
